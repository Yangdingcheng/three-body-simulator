# 三体游戏模拟器 · Three-Body Simulator

一个**单文件 HTML**的三体世界模拟游戏：双击 `index.html` 就能玩，不装任何东西、不联网、没有构建步骤。

## 它模拟了什么

这不是一段预设动画——**三个太阳的每一帧位置，都是牛顿万有引力 + RK4 数值积分实时算出来的**。三体问题没有解析解，混沌是算出来的，不是演出来的：

- **真实引力**：三颗等质量恒星互相拉扯，行星作为无质量质点在引力场中运动（软化参数避免贴脸奇点）。
- **真实温度**：地表平衡温度由三颗太阳的辐射通量合成（与距离平方成反比，$T \propto F^{1/4}$），再叠加行星热惯性——升温降温都有滞后，极寒和酷热都是攒出来的。
- **真实昼夜**：行星在自转。站在地表看，每颗太阳都有自己的升起和落下——长夜、双日凌空、三日凌空都是几何算出来的。
- **纪元判定**：用最近 4 年的温度采样判断稳定纪元 / 混沌纪元，和小说里三体人用历法与观测做的事一样。

## 玩法（还原小说里的游戏机制）

- **文明系统**：从第 141 号文明开始（石器时代），在稳定纪元里发展人口与科技：青铜 → 铁器 → 蒸汽 → 电气 → 信息 → **原子时代（通关）**。
- **脱水 / 浸泡**：混沌纪元恶化时可以全民脱水躲灾——脱水状态不发展、也不死于冷热；等稳定纪元回来再浸泡复苏。时机判断错了，一样会被筛掉。
- **毁灭与重生**：持续酷热、严寒长夜、三日凌空、坠入太阳、被甩出星系，都会终结一号文明。下一号文明带着"遗迹启示"重生，发展速度有加成——和小说一样，文明是在毁灭的灰里叠起来的。
- **编年史**：右侧日志会以小说的口吻记录每一号文明的生灭。

## 四种初始构型

| 构型 | 说明 |
|---|---|
| 混沌三体 | 经典乱局：温度在 -47℃ 到近 400℃ 之间横跳，太阳还可能被弹弓甩出星系 |
| 稳定纪元 | 紧密双星 + 30 单位外的第三颗：气候温和，先在这里学会怎么玩 |
| 8 字轨道 | 数学家找到的等质量三体周期解——太阳的舞步精确重复，但行星的气候照样不太平 |
| 三日凌空 | 极端局：开局就是地狱，开局立刻脱水是你唯一的生路 |

## 运行

```bash
# 方法一：直接双击 index.html
# 方法二：起个静态服务器
python3 -m http.server 8000   # 然后打开 http://localhost:8000
```

也可以打开 GitHub Pages（仓库 Settings → Pages → 选 main 分支）直接在线玩。

## 技术说明

- RK4 积分，固定步长 0.004 时间单位；1 游戏年 = 10 时间单位；行星自转周期 = 1 时间单位。
- 温度模型：$F = \sum (4.1/d_i)^2$，$T_{eq} = 283 \cdot F^{0.25} - 273.15$（℃），热惯性时间常数 0.9。
- 纪元判定：每 0.05 年采样，近 80 个样点中 ≥75% 处于 -12℃..42℃ 且无极端值 → 稳定纪元。
- 全部逻辑约 500 行 JavaScript，就在 `index.html` 里，欢迎魔改：换质量、加行星、改文明规则都很容易。
