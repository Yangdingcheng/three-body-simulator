# 三体游戏模拟器 · Three-Body Simulator

一个运行在浏览器里的 **3D 三体世界模拟游戏**：真实三维 N 体引力实时积分，三个太阳、一颗会结冰也会燃烧的行星、和在它们底下挣扎求生的文明。

**主画面就是地面世界本身**：程序生成的山川、河流、湖泊、森林环绕着文明的村庄，天上有云、有鸟、有三个真实升起落下的太阳；左上角小窗是轨道监控，盯着太空里的引力之舞。

## 先说清楚：物理是真的

这不是预设动画。**每一帧，三个太阳的位置都是牛顿万有引力在三维空间里用 RK4 方法一步步算出来的**，三体问题没有解析解，混沌是算出来的，不是演出来的：

- **三维 N 体引力**：恒星互扰、行星受摄动、彗星乱入，全在同一个积分器里。
- **气候是算的**：地表温度 = 三颗太阳辐射通量合成（距离平方反比，T ∝ F^1/4）+ 行星热惯性。行星表面纹理会随气候实时变化：极寒时冰盖扩张，炽热时大地焦土化。
- **昼夜是算的**：行星有自转和转轴倾角。站在地表（游戏内有地表视角），每颗太阳都有自己的升起与落下——长夜、双日凌空、三日凌空都是几何结果。
- **纪元是判的**：用最近 4 年的温度采样判定稳定/混沌纪元，和三体人用历法做的事一样。

## 两种模式

### 文明模式（剧情向）
从第 **141 号文明**开始（石器时代）。在稳定纪元发展人口与科技，在混沌纪元求生：

- **脱水 / 浸泡**：混沌恶化时全民脱水存入仓库躲灾，稳定纪元回来浸泡复苏——时机错了，照样被筛掉。
- **科技树**：科研点点亮 6 条科技——精确历法（**克隆整个星系向前积分，预报未来 8~22 年的纪元带**）、脱水工艺、地下城市（致命灾害时以重创换不灭）、深空观测、生态穹顶、基础物理（没有它，原子时代的大门推不开）。
- **剧情抉择**：稳定纪元的第一项决议、人列计算机、严寒预警、飞星异象、黄金时代……每个选择都有代价，游戏会暂停等你拍板。
- **毁灭与重生**：酷热、严寒长夜、三日凌空、彗星撞击、坠入太阳、被甩出星系——下一号文明带着遗迹启示重生，发展更快。
- **通关**：任一文明活着进入**原子时代**。还有 11 个成就等着解锁。
- **活生生的地面世界**（v4 主画面）：地形由噪声算法生成——雪山、河谷、湖泊、260 棵森林环绕着村庄高原；季节与气候实时重绘大地：极寒时万里雪原、河流封冻，炽热时草木焦黄。你能直接看到小人们在干活：稳定纪元播种赶集、极寒时围火取暖、酷热时躲进阴影；按下脱水，他们会走进仓库、躺上架子变成人形纤维，浸泡时水花四溅地站起来。村落会随文明等级长大：帐篷篝火 → 房屋 → 工厂烟囱 → 高塔天线 → 原子穹顶；天气实时同步：飘雪、落雨、热浪火星，晴好时还有鸟群掠过。文明毁灭时，村庄化为倾颓的废墟。

### 沙盒模式（造物向）
没人会死，宇宙归你：

- **改写物理定律**：引力常数 G、引力幂次（真实宇宙是 2，改成 1.5 或 2.6 看世界如何重组）实时生效。
- **管理太阳**：调质量、踢一脚（随机扰动）、添加第 4、第 5 颗太阳、移除任意一颗。
- **召唤彗星**、重置行星轨道——纯粹的引力游乐场。

## 技术说明

- 渲染：Three.js + UnrealBloom 辉光后处理；太阳光晕、行星大气菲涅尔散射、程序化气候纹理均为实时生成。
- 物理：RK4 固定步长 0.004；1 游戏年 = 10 时间单位；行星自转周期 = 1 时间单位，转轴倾角 0.41 弧度。
- 温度模型：F = Σ(4.1/d_i)²，T_eq = 283·F^0.25 − 273.15（℃），热惯性时间常数 0.9。
- 历法预报：把当前系统状态深拷贝后以更粗步长向前积分，按 0.1 年采样温度分类纪元——混沌系统里这是真本事，不是作弊码。
- 全部游戏逻辑在一个 `index.html` 里（约 1900 行），欢迎魔改。
